# 🎛️ DeckMix

**DeckMix** is a high-performance, browser-based DJ system designed with a professional layout. It is engineered to integrate seamlessly with hardware controllers using native web technologies.

---

## ✨ Key Features
* **Browser-Powered Audio Engine:** Built on top of the **Web Audio API** for low-latency mixing, EQ adjustments, and track processing.
* **Hardware MIDI Integration:** Full support for **Web MIDI API** to connect and map physical DJ controllers like the Pioneer DDJ-FLX4.
* **Local File System Access:** Utilizes the **File System Access API** to load local music libraries directly from your computer safely and efficiently.
* **Professional Workflow:** Familiar dual-deck interface, waveform visualizers, cue points, and mixer controls.

---

## 🚀 Tech Stack
* **Language:** TypeScript
* **APIs:** Web Audio API, Web MIDI API, File System Access API
* **Environment:** Modern Web Browsers (Chrome / Edge)
