## ממצא אמיתי תוך כדי אימות (לא רק בדיקה שנוספה)

בכתיבת `scripts/verify-privacy-a11y.mjs` (Playwright אמיתי מול `npm run dev`,
Chromium 1194) התגלה **שטבעת הפוקוס נעלמת בכל רכיב שמערבב `outline-none` עם
`focus-visible:outline-*`**. מוסכמת ה‑Tailwind הזו נשענת על משתנה CSS משותף
(`--tw-outline-style`), ו‑`outline-none` קובע אותו ל‑`none` **בלי שום תנאי**
— לא רק במצב "לא פוקוס". אז גם כש‑`:focus-visible` תפס (אומת ישירות עם
`el.matches(':focus-visible')` — `true`), ה‑`outline-style` בפועל נשאר
`none` בכל רכיב שנשא את שתי המחלקות יחד: `HintIcon`, וה‑`<select>`ים ב‑
Settings/TopBar/AiControlBar. שורת הטבלה ב‑`Library.tsx` תוקנה עם תוספת
חד‑שורתית (`focus-visible:[--tw-outline-style:solid]`) שדורסת את המשתנה
בחזרה בזמן פוקוס; שאר המקומות נשארו בכוונה בחוץ — תיקון רוחבי מעבר להיקף
הגרסה הזו, נרשם ב‑`HANDOFF.md`. **`Button` לא נפגע** — הטענה הראשונה שלי
כללה אותו בטעות; אין לו `outline-none` בכלל (`controls.tsx` — `base` של
`Button` לעולם לא כולל את המחלקה), ו‑`change-reviewer`'s תפס את זה בבדיקה
ישירה עם Tab אמיתי + `getComputedStyle` לפני שהתיעוד יצא לדרך עם טענה
גורפת שגויה.

## תיקון המשך (14/09, אחרי המיזוג): התיקון החלקי יצר בעיה משלו

שלום דיווח, אחרי שה‑PR כבר מוזג, שלחיצת Tab "מסמנת את כל השירים ביחד". זה
לא היה נכון פשוטו כמשמעו (אף פעם לא יותר משיר אחד מודגש בבת אחת — אומת עם
30 שירים מזויפים ולחיצות Tab חוזרות), אבל הדיווח המדויק יותר שהתקבל אחרי
שאלת הבהרה חשף באג אמיתי: **המעבר בין שורה לתאים שלה (בורר ז'אנר, שדה
הערה, כפתורי Load) ביטל את טבעת הפוקוס לגמרי**, כי כל אחד מהם נשא בדיוק את
אותו צירוף `outline-none`+`focus-visible:outline-*` שתועד למעלה כחוב פתוח.
התוצאה בפועל: הטבעת "מהבהבת" רק בעצירה אחת מתוך חמש (השורה עצמה) ונעלמת
בארבע האחרות — בדיוק התחושה שהמשתמש תיאר, "המשתמש לא רואה איפה הפוקוס
שלו". ההחלטה המקורית "לתקן רק את השורה, זה חוב נפרד" הייתה שגויה בפועל:
תיקון חלקי של הפיצ'ר יצר חוויה גרועה יותר מלפני התיקון.

**תוקן במלואו** — אותה שורת קוד (`focus-visible:[--tw-outline-style:solid]`)
נוספה לשבעת המקומות שנשאו את הצירוף: שורת הטבלה (כבר היה), תיבת החיפוש,
בורר הז'אנר ושדה ההערה ב‑`Library.tsx`, ה‑`<select>` ב‑`Settings.tsx`/
`TopBar.tsx`, השדה ב‑`AiControlBar.tsx`, ו‑`HintIcon` ב‑`controls.tsx`.
`scripts/verify-privacy-a11y.mjs` קיבל שתי בדיקות חדשות שמדמות בדיוק את
התרחיש שדווח (Tab מהשורה לארבעת התאים שלה ולשורה הבאה, כל עצירה חייבת
`outlineStyle: solid`) — **19/19**. `npm run check` ירוק (אותם 8 כשלים
ידועים). חוב `--tw-outline-style` סגור לגמרי; אין יותר רכיב שנושא את
הצירוף השבור.
