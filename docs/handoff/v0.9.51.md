# v0.9.51 — הניתוח ברקע מפנה מקום למוזיקה (07/10)

**הבקשה (שלום 07/10):** אחרי כל גרסה הספרייה מנותחת מחדש, ומה שהוא מנגן בזמן הזה קופץ ומגמגם עד שהניתוח נגמר. "מה אפשר לעשות כדי
שהשירים יתנגנו בלי להפסיק את הניתוח ברקע?"

**הגורם (מהקוד, לא נמדד במחשב של שלום):** הנגינה רצה ב-AudioWorklet, על חוט האודיו, ולא תלויה ב-main thread — המיקום נמדד מהשעון של
המעבד עצמו (`players.ts`), אז גם לולאת ה-SYNC לא "קופצת" מעומס. מה שכן יכול להרעיב את חוט האודיו הוא מעבד עמוס: מעבר ה-hash קרא 4 קבצים
שלמים במקביל, מעבר ה-BPM פענח 2 שירים במקביל (פענוח שיר מלא + Worker), ואחריהם מעבר הדמיון ומעבר השירה. בפרופיל `interactive` (ברירת
המחדל) הבאפר של הכרטיס קטן מאוד, וכל עיכוב בחוט האודיו נשמע.

**מה נבנה:** `src/core/background-pace.ts` — כשדק מנגן, כל העבודות הכבדות של מעברי הרקע (פענוח + ניתוח BPM שלא
מהמטמון, טביעת דמיון, פס שירה) רצות **אחת בכל פעם**, ואחרי כל אחת יש מנוחה באורך העבודה עצמה (מינימום 250ms) — הרקע מחזיק לכל היותר
כחצי ליבה. כשאין נגינה — מהירות מלאה כמו קודם. שיר שנטען לדק (`analyseDeckTrackNow`, `loadTrackToDeck`) **לא** מואט. תגית בכותרת
הספרייה: "ניתוח מואט בזמן נגינה", כדי שההאטה לא תהיה שקטה. מעבר ה-hash **לא** מואט: שיר שנטען לדק מחכה לכל המעבר הזה
(`jumpDeckTrackQueue`), והוא רץ פעם אחת בטעינת הדף.

**סקירה עצמאית (change-reviewer):** מצאה שאחרי שהנגינה נעצרת התור נשאר אחד-אחד עד שנגמר (המקום הועבר ישר לממתין הבא) — תוקן, ובדיקה
"several looping workers" מחזיקה את זה. חוב שנשאר: עבודה שלא מסתיימת לעולם (פענוח/Worker תקוע, אין timeout) תופסת בזמן נגינה את המקום
היחיד ועוצרת את כל מעברי הרקע.

**בדיקות:** `tests/core/background-pace.test.ts` — מהירות מלאה בלי נגינה, אחת-אחת עם מנוחה בזמן נגינה, מנוחת מינימום, עבודה שנכשלה
משחררת את התור, עצירת נגינה מבטלת את המנוחה הבאה. `npm run check` ירוק.

**מה לא נבדק:** לא הורץ בדפדפן מהקונטיינר, ואין מדידה של גמגומים — רק שלום יכול לשמוע את זה. אם עדיין יש קפיצות: Settings → Audio
latency → `Balanced` ורענון הדף (באפר גדול יותר, תגובה קצת פחות מיידית לג'וג), ואחריו לשקול לא לקרוא מחדש את כל 4.8GB בכל טעינה רק כדי לחשב hash
(מטמון לפי שם+גודל+תאריך) — שינוי בזהות השירים, לכן נפרד.
