## מה נבנה

▾ בכותרת של כל עמודה, אותו כפתור ואותה רשימה כמו ב-Genre (נפתחת למעלה כשאין מקום למטה, Esc סוגר):

| עמודה | סוג הסינון |
| --- | --- |
| Title | טקסט שמופיע בשם (גם בשם הקובץ כשאין שם בתגית) |
| Artist, Note | טקסט, ועוד "Hide/Only No artist" ו-"Hide/Only No note" |
| Type | סימון: MP3 / WAV / ... עם מספר שירים |
| Key | סימון, לפי סדר הגלגל (Camelot), באיות שהעמודה מציגה; "No key" שורה משלה |
| BPM | מ- עד, כל צד אופציונלי |
| Time | מ- עד, ב-`3:30` או בדקות (`5`, `2.5`) |
| Played | Never played / 24 שעות / 1–7 ימים / 7–30 ימים / מעל 30 יום |

- כל הסינונים יחד (וגם יחד עם החיפוש ועם Genre). הכותרת אומרת "N of M".
- **Type ממוין עכשיו** (לחיצה על הכותרת). שאר העמודות כבר מוינו מ-v0.8.0. Load — אין מה למיין או לסנן, זה כפתורים.
- **לא שקט:** טווח BPM/Time מסתיר שירים בלי ערך — הרשימה כותבת כמה. תיבה שלא נקראת ("zz") כתוב לידה "Can't read that — not applied", לא נקראת כ-0. סינון ריק (כלום לא מסומן, תיבה ריקה) = אין סינון, לא טבלה ריקה.
- כשלא נשאר כלום — כל סינון הוא כפתור ✕ משלו במסך הריק (`BPM: 125–130 ✕`).
