# v0.9.54 — מתג ב-Settings ל-Balanced בזמן ניתוח, כבוי כברירת מחדל (07/10)

**הבקשה (שלום 07/10, על v0.9.52–53):** "תעשה לפיצ'ר הזה כפתור ב-SETTINGS ושיהיה כבוי בדיפולט".

**מה נבנה:** `analysisCushion` ב-`core/settings.ts` (Settings → Hardware, "Balanced while the library analyses"), ברירת מחדל `false`.
כבוי — הדף עולה תמיד על Audio latency כמו שבחר, ואין תגיות "סאונד מוגן", רענון אוטומטי או כפתור "הפעל ג'וג מהיר" (כולם תלויים
ב-`latencyCushioned()`). דלוק — ההתנהגות של v0.9.52–53. כמו `latency`, המתג נקרא לפני ש-IndexedDB עונה, אז הוא ממוראר ל-
`deckmix:bootCushion` ב-`boot-latency.ts`, ומסומן "Takes effect after a reload".

**לא מושפע:** ההאטה של v0.9.51 (ניתוח שיר-שיר בזמן נגינה) נשארת פעילה תמיד; המתג הוא רק לבאפר ולרענון.

**בדיקות:** `tests/core/analysis-latency.test.ts` — כבוי (ברירת מחדל) לא מרים כלום גם כשיש ניתוח. `npm run check` ירוק. לא הורץ בדפדפן.
