# v0.8.37 — Mix Assist: כפתורי להאיץ / לשמור / להאט (25/09)

## הבקשה

שלום: "Mix Assist לפי אנרגיה". בחר "כפתור כיוון" (להעלות / לשמור / להוריד) ו"אני אדרג 20 שירים" כדי שנדע אם
המדידה נכונה.

## המחקר — ומה הוא הראה

אין אמת-מידה מוכנה: רק 5 מ-362 קבצים נושאים תגית Energy של תוכנה אחרת. שלום דירג 20 שירים (אחד לא
מתפענח בדפדפן — 19 נכנסו), 1 = רגוע, 10 = מפוצץ, לפי השיא של השיר.
`scripts/dump-waveform-bands.mjs` שמר את `analysis.bands` (מה שהאפליקציה כבר מחשבת לכל שיר) לכל הספרייה;
`scripts/experiment-energy.mjs` השווה (Spearman) כל מדד לדירוגים. **המדדים והשילובים נכתבו לפני שראינו דירוג.**
הדירוגים עצמם ב-`%TEMP%\energy-ratings.json` במחשב של שלום (לא ב-repo), ורשימת 20 השירים ב-
`%TEMP%\energy-rate-list.txt`; להריץ שוב: `node scripts/dump-waveform-bands.mjs` ואז
`node scripts/experiment-energy.mjs %TEMP%\energy-ratings.json`.

| מדד | הסכמה |
| --- | --- |
| BPM | **0.64** |
| חלק השיר ב"עוצמה מלאה" (הפוך = יותר בנייה/דרופים) | **−0.63** |
| עוצמה (dB) | −0.15 |
| חוזק הקיק | −0.02 |
| טרבל / בס | 0.19 / −0.05 |
| השילובים שתוכננו מראש | −0.61 … 0.19 — **נכשלו** |

שלום הסביר אחר כך: **הוא דירג קודם כל לפי ז'אנר** — היפ-הופ 5, מזרחית 7–8, טכנו 8–9, טראנס 10. זה מסביר את
ה-BPM: הז'אנרים שלו מסודרים בערך לפי מהירות. עוצמה לא אומרת כלום (הכל ממוסטר חזק באותה מידה).

**המסקנה:** בתוך רשימת Mix Assist (±8% BPM) אין מדד שמבחין באנרגיה באמינות — ה"דרופים" יורדים ל-−0.56 בלי
טראנס, על 16 שירים. שלום בחר לבנות **כפתורי מהירות** שאומרים מה הם עושים, לא "אנרגיה".

## מה נעשה

- `MixMatch.tempoStep` (`src/core/recommend.ts`): כמה השיר מהיר/איטי מה**שיר** שבדק, בכפולה המנצחת —
  **לא מהפיידר**: `matchTier` נמנע מסידור לפי טמפו בדיוק כי שורות קפצו כשרוכבים על הפיידר.
- `orderMixList(..., { direction })`: בתוך כל שכבה (הדוק / רופף / כבר נוגן) — השירים שהולכים בכיוון שנבחר קודם,
  הצעד הקטן קודם (סט עולה בהדרגה); השאר אחריהם בסדר הצליל. **שום שורה לא מוסתרת.** בלי כפתור — הסדר הקודם.
- `Library.tsx`: שלושה כפתורים ליד "♫ mixable" (Mix Only בלבד, מוסתרים כשמיון עמודה פעיל — הוא מנצח, וכפתור
  דולק שלא משנה כלום הוא הדילוג השקט שהאפליקציה אוסרת). קליק שני מכבה. כל שורה אומרת "2% faster than deck
  A's track" כשכפתור פעיל.
- **אחרי סקירה עצמאית:** "same" שובר שוויון לפי צליל (תגיות BPM שלמות שמות הרבה שורות על אותו צעד);
  כשכפתור פעיל, `matchReasons(match, { trackTempo: true })` מחליף את סיבת הטמפו במקום להוסיף שנייה — שורה אמרה
  "same tempo as deck A" (עם פיידר) וגם "3% faster" (בלי); התווית "Tempo: …" באותו תנאי כמו הכפתורים; החצים
  `aria-hidden`. בדיקות נוספו: שכבה מנצחת כיוון, מיון עמודה מנצח הכל, hidePlayed, שוויון ב-same.
- בכוונה **לא** נגעתי ב-`hints.ts` (בלי HintIcon חדש) — השיחה המקבילה (v0.8.38) עורכת אותו.
