# v0.9.50 — the deck shows the key it is heard in — 07/10

## הבקשה

שלום, 07/10, אחרי שבדק Key sync (v0.9.21): הצליל השתנה, אבל (1) לא ראה את ההודעה שהאפליקציה אמורה להציג,
(2) אין שום סימן לסולם הנוכחי של השיר, עדיף ליד ה-BPM, (3) לא בטוח שהסולם חזר למקור אחרי ביטול, בגלל (2).

## מה נבנה

- ליד "BPM" בכל דק מוצג עכשיו הסולם: `8A` כשהוא הסולם של השיר, `8A→9A` (בצבע accent) כשהדק נשמע בסולם אחר.
  הסולם הנשמע מחושב מאותו חישוב של Key sync (`heardSemitones`): עם Key lock זו ההזזה של Key sync, בלי Key lock הטמפו מזיז כמו תקליט.
  אין שורה חדשה: זה על שורת ה-BPM הקיימת, כדי לא להזיז את הדק (ר' v0.9.46, הדק מלא ב-710px).
- ביטול Key sync מחזיר את הכתובת ל-`8A` בלבד. זה הסימן לחזרה למקור.
